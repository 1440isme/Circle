# Continuous Learning Layer

Continuous engineering knowledge layer for CIRCLE.

---

## Purpose

When engineers or AI coding agents discover a pattern, solve a tricky bug, or establish a superior workflow during sprint iterations, they capture the insight here instead of letting it vanish.

## Files
- [`best-practices.md`](best-practices.md) — Proven engineering conventions and coding recipes in CIRCLE.
- [`trends.md`](trends.md) — Code evolution directions, refactoring goals, and technical debts being paid down.
- [`lessons.md`](lessons.md) — Incident post-mortems, bug root causes, and lessons learned.

---

> **Workflow:** Changes to this layer should be proposed via PRs referencing relevant issues or bug fixes.
