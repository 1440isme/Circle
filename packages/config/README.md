# packages/config — CIRCLE Shared Tooling Configuration

Centralized configurations for build tools, linters, formatters, and TypeScript compilers across all packages and applications in the repository.

## Package Contents
- `eslint/`: Shared ESLint configurations (NestJS, React, React Native)
- `prettier/`: Shared Prettier formatting rules
- `typescript/`: Shared base `tsconfig.json` configurations
- `tailwind/`: Shared Tailwind design tokens, colors, typography scales
