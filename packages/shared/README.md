# packages/shared — CIRCLE Shared Utilities

Platform-agnostic utilities, string formatters, date helpers, validation logic (Zod schemas), and cryptographic helper functions shared across backend, web, and mobile.

## Package Contents
- `validators/`: Zod validation schemas shared between client forms and backend DTOs
- `formatters/`: Vietnamese phone number, date/time relative display, text truncation
- `constants/`: Business constants, file size limits, rate limits, pagination defaults
