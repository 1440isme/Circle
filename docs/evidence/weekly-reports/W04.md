### 1. Những việc đã làm được:
- Thiết lập hạ tầng mã nguồn Monorepo cho toàn bộ hệ thống gồm Backend (NestJS), Web Application (Next.js) và Mobile Application (React Native/Expo).
- Khởi tạo môi trường phát triển cục bộ qua Docker Compose với PostgreSQL 16 và Redis 7.
- Thiết lập quy trình làm việc Git/GitHub: quy chuẩn đặt tên nhánh (branching conventions), bắt buộc Peer Review khi mở Pull Request và tích hợp luồng kiểm tra tự động (CI) cơ bản.
- Xây dựng hệ thống xác thực và phân quyền: cơ chế cấp phát và luân chuyển JWT Access Token / Refresh Token an toàn, mã hóa mật khẩu và phân quyền RBAC.
- Xây dựng hoàn chỉnh các chức năng quản lý tài khoản cơ bản: đăng ký, đăng nhập và cập nhật hồ sơ cá nhân (User Profile).

### 2. Những việc chưa làm được:
- Chưa hoàn thiện tích hợp dịch vụ gửi email OTP tự động phục vụ khôi phục mật khẩu (tạm thời ghi nhận mã OTP tại môi trường log nội bộ để phục vụ phát triển).

### 3. Những vướng mắc, khó khăn:
- Cấu hình chia sẻ mã nguồn dùng chung (DTO, Types, Validators) trong Monorepo giữa NestJS, Next.js và Expo cần xử lý cẩn thận để tránh lỗi không tương thích phiên bản build trên mobile.
- Việc đồng bộ cookie xác thực giữa trình duyệt Web và hệ thống lưu trữ SecureStore trên ứng dụng di động đòi hỏi thiết kế lớp xử lý Token độc lập.
