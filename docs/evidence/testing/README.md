# BẰNG CHỨNG KIỂM THỬ PHẦN MỀM & ĐỘ PHỦ COVERAGE
## Thư mục Lưu trữ Kết quả Kiểm thử Tự động — CIRCLE

Thư mục này lưu trữ:
- Báo cáo kết quả kiểm thử tự động đa tầng: Jest Unit/Integration Tests, Supertest API Tests và Playwright E2E Tests.
- Báo cáo độ phủ dòng lệnh Core Services đạt $\ge 70.0\%$.
- Sổ theo dõi lỗi (Defect Backlog) với 0 lỗi Blocker/Critical tại thời điểm nghiệm thu.
