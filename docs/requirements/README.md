# Software Requirements Specifications (SRS)

Formal software requirements, user stories, and business rules for CIRCLE.

---

- `EPIC-AUTH`: Authentication & Identity Management
- `EPIC-CIRCLE`: Circles, Channels & Communities
- `EPIC-CHAT`: Real-time Messaging
- `EPIC-RTC`: Audio & Video WebRTC Calling
- `EPIC-ADMIN`: Moderation & Administration
